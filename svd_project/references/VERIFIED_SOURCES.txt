[15] Anil Damle - Cornell CS 3220 SVD notes
https://www.cs.cornell.edu/courses/cs3220/2020fa/SVD.pdf
The PDF is undated; it is hosted in the Fall 2020 course directory.
Page 2, "The SVD as a sum of rank one matrices," writes a matrix as a weighted sum of outer products.
Page 3, "Best approximation via the SVD," Theorem 1, gives the best low-rank approximation and the discarded-singular-value Frobenius error.
Citations added to Section 2's weighted-basis interpretation and tail-error formula.
This batch theorem applies to the original matrix's SVD. It does not turn a repeatedly truncated incremental approximation into the global batch optimum.

[16] Yangwen Zhang (2022) - Numerical orthogonality in incremental SVD
An answer to an open question in the incremental SVD.
https://arxiv.org/abs/2204.05398v2
https://arxiv.org/pdf/2204.05398v2
Use this pinned version: arXiv version 2 was revised April 30, 2022. A later version has a different title.
Section 2, pages 3-4, discusses the update through a smaller core; pages 5-6 discuss orthogonality loss and reorthogonalization.
Citation added to the numerical-stability explanation in Section 3, with a short clause identifying roundoff drift.
The paper supports the motivation for keeping a basis orthonormal. The report does not claim its expanded-basis QR is Zhang's improved algorithm. The paper's weighted setting specializes to the ordinary inner product when its weight matrix is the identity.

OPTIONAL READING - NOT ADDED TO THE REPORT BIBLIOGRAPHY

Gilbert Strang, MIT 18.065, Lecture 6: Singular Value Decomposition (SVD), Spring 2018.
https://ocw.mit.edu/courses/18-065-matrix-methods-in-data-analysis-signal-processing-and-machine-learning-spring-2018/resources/lecture-6-singular-value-decomposition-svd/
Start with the Description and Summary. The lecture explains rank-one pieces ordered by importance and orthonormal singular-vector bases.
Useful for explaining basis patterns and singular values aloud. No exact publication day is claimed.

Hiba Fareed and John R. Singler, Error Analysis of an Incremental POD Algorithm for PDE Simulation Data, 2018 preprint.
https://arxiv.org/abs/1803.06313v1
https://arxiv.org/pdf/1803.06313v1
Section 3.2, Theorem 2 on page 9 and Corollary 1 on page 10, provides context for accumulated truncation error.
This is optional advanced reading. Its operator-norm bounds for a one-column, tolerance-based weighted algorithm are not direct bounds for this project's blockwise fixed-rank Frobenius errors.

READING ORDER FOR UNDERSTANDING

1. September 18: array shapes and matrix multiplication.
2. MIT Lecture 6: what the SVD components mean.
3. Cornell pages 2-3: weighted components and the batch error formula.
4. November 6 and November 9: projection, QR, reduced factors and reconstruction.
5. September 25: why floating-point tests use tolerances.
6. Zhang Section 2: numerical stability motivation, if asked in the oral exam.
The Fareed-Singler paper can remain optional.

Source citations document concepts and software operations. They do not establish who wrote project code or generated figures and report text.
